# Generative AI & Agentic AI Professional Development Program

**Official Learning Path and Resource Hub**

## 📜 Overview

Welcome to the official repository for our Generative AI & Agentic AI learning path. This program is designed to equip our team with the essential skills and advanced knowledge required to design, build, and deploy sophisticated AI-powered applications.

This repository serves as the central hub for all session materials, including presentation decks, code snippets, notebooks, and links to mandatory and supplementary learning resources.

## 🎯 Learning Objectives

Upon completing this program, participants will be able to:

  - **Understand** the fundamental concepts of Generative AI, Large Language Models (LLMs), and prompt engineering.
  - **Build** end-to-end Retrieval-Augmented Generation (RAG) applications using LangChain.
  - **Develop** complex, stateful workflows and multi-agent systems using LangGraph.
  - **Implement** advanced agentic patterns, including tool usage, feedback loops, and adaptive RAG.
  - **Gain proficiency** with cutting-edge agentic frameworks such as Microsoft Autogen and Crew AI.

## 📚 Program Structure

The learning path is divided into three core modules, progressing from foundational knowledge to advanced application development.

  * **Module 1: Foundations of Generative AI**
  * **Module 2: Building with LangChain & RAG (Mandatory)**
  * **Module 3: Advanced Agentic AI Frameworks (Mandatory)**

## 📂 Repository Contents

This repository is structured by modules. Each module folder contains:

  - **`/decks`**: Presentation slides for each session.
  - **`/code`**: Code snippets, Jupyter notebooks, and other materials used during the sessions.
  - **`/resources`**: Links to supplementary articles, papers, and documentation.

## Prerequisites

A solid understanding of **Python programming** is required to fully benefit from Modules 2 and 3. Prior experience with machine learning concepts is beneficial but not mandatory for the foundational module.

## 🏁 Getting Started

1.  **Clone the repository** to your local machine to access all materials offline.
2.  Follow the modules sequentially, starting with Module 1.
3.  Ensure you have completed the mandatory courses before proceeding to the next module.
